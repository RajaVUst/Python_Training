# Assignment 1 - Day 2

This assignment contains two parts covering Python string manipulation and basic arithmetic operations.

## Part 1 - String Manipulation

The script accepts one sentence from the user and displays:

- Total character count
- Uppercase sentence
- Lowercase sentence
- Reversed sentence
- Word count
- First word
- Last word
- Palindrome status

The palindrome check ignores spaces and letter case.

## Part 2 - Simple Calculator

The calculator accepts two numbers and displays the results of:

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Floor Division (//)
- Modulus (%)
- Power (**)

The results are displayed as a neatly aligned table using Python f-string formatting.

## Concepts Used

- `input()`
- Type casting with `float()`
- String methods
- `split()`
- String slicing
- `len()`
- Boolean comparison
- Arithmetic operators
- f-string formatting
- Alignment formatting
