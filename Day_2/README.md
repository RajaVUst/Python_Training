---------Day-2----Assignment----------String Manipulation & Calculator-------------------------------

This Day2.ipynb file contains all those exercise and  Day 2 Assignment, divided into two parts.


------------------------Part-1-String Manipulation Script-------------------

The program asks the user to enter a sentence and displays:

Total character count
Sentence in uppercase
Sentence in lowercase
Reversed sentence
Word count
First word
Last word
Whether the sentence is a palindrome, ignoring spaces and letter case

The palindrome check is performed by creating a cleaned version of the sentence and comparing it with its reversed version.

-------------------------Part 2 — Simple Calculator, Revisited---------------------

The program asks the user to enter two numbers and converts them to float.

It calculates and displays the following operations in a neatly aligned table:

Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Floor Division (//)
Modulus (%)
Power (**)

The results are formatted using f-strings, fixed-width fields, alignment, and two decimal places.

Concepts Used
input()
float()
len()
.upper()
.lower()
.split()
.strip()
.replace()
String indexing and slicing
String reversal
Arithmetic operators
Comparison operators
f-string formatting and alignment

Note: The assignment is implemented without loops or if statements, using only the concepts covered in the Day 2 reference notes.
