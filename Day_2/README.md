# Day 2 Python Training — String Manipulation

This assignment covers the basics of Python string manipulation, formatting, operators, and debugging.

## Topics Covered

- String indexing and slicing
- String methods like `.title()`, `.capitalize()`, `.lower()`, `.upper()`, `.strip()`, `.replace()`, `.split()`, `.find()`, `.count()`, `.endswith()`, and `.isalnum()`
- String reversal and palindrome checking
- Boolean and comparison operators
- f-strings and string alignment
- Number formatting
- Basic Python traceback and error handling
