Day 2 Assignment — String Manipulation & Calculator

This Day2.ipynb notebook contains the Day 2 Python exercises and the graded assignment, organized into two parts.

Part 1 — String Manipulation

The program asks the user to enter a sentence and displays:

Total character count

Sentence in uppercase

Sentence in lowercase

Reversed sentence

Word count

First word

Last word

Whether the sentence is a palindrome, ignoring spaces and letter case

For the palindrome check, a cleaned version of the sentence is created by removing spaces and converting the text to lowercase. The cleaned sentence is then compared with its reversed version.

Part 2 — Simple Calculator

The program asks the user to enter two numbers and converts both inputs to float.

It performs and displays the following mathematical operations in a neatly aligned table:

Addition (+)

Subtraction (-)

Multiplication (*)

Division (/)

Floor Division (//)

Modulus (%)

Power (**)

The results are presented using f-strings, fixed-width fields, alignment, and two decimal places for clear formatting.
