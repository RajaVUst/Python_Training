# Assignment 1 — Day 2

This repository contains my Day 2 graded Python assignment.

## Part 1 — String Manipulation

The program takes a sentence as input and displays:

- Total character count
- Uppercase and lowercase versions
- Reversed sentence
- Word count
- First and last word
- Whether the sentence is a palindrome (ignoring spaces and letter case)

## Part 2 — Simple Calculator

The program takes two numbers as input and calculates:

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Floor Division (//)
- Modulus (%)
- Power (**)

The results are displayed as a neatly aligned mini-table using Python f-string formatting.
