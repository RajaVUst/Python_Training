Day 2 — Python Strings & Calculator

This repository contains my Day 2 Python assignment, covering string manipulation, debugging, formatting, and basic calculator operations.

Assignment 1
Part 1 — String Manipulation

The program asks the user to enter a sentence and performs different string operations:

Calculates the total character count
Converts the sentence to uppercase and lowercase
Reverses the sentence
Calculates the word count
Displays the first and last word
Checks whether the sentence is a palindrome, ignoring spaces and letter case
Part 2 — Simple Calculator

The program asks the user to enter two numbers and performs:

Addition +
Subtraction -
Multiplication \*
Division /
Floor Division //
Modulus %
Power \*\*

The calculator results are displayed in a formatted table using f-strings and alignment.
